# AWSherlock v0.5.1 — Contextual Investigation Engine

From security findings to explainable investigations. **This patch-numbered
release deliberately includes substantial feature additions.** All implemented
investigation functionality is retained; schema versions are independent of
the package version. These notes are prepared for publication, pending approval.

## Highlights

- **Evidence-Aware Investigation Engine:** derives investigations from all five
  existing Lead patterns, preserving exact Finding and Relationship references.
  Observed configuration, deterministic inferences and unknown conditions remain
  distinct in JSON and HTML.
- **Contextual Risk Prioritization:** separate, bounded 0–7 review priority with
  individual contributing factors. Current patterns remain PROVISIONAL; identity
  conflicts yield UNASSESSED/BLOCKED instead of unsupported certainty. Finding
  severity and original Lead priority are unchanged.
- **Interactive Investigation Graph:** local SVG/JavaScript, investigation
  selection, search, inferred-association filtering, keyboard inspection and
  evidence navigation. Bounded rendering, omission counts and accessible text
  support large or incomplete captures. No backend or CDN is required.
- **Offline investigations:** `investigate --contextual --output json` and
  `investigate --contextual --output html --report-file investigations.html`
  consume saved snapshots; optional `--lead-id` selects one investigation.
  Original Evidence Pack exports remain available without `--contextual`.
- **Security and reliability:** shared sanitized coverage diagnostics, additional
  throttling/timeout error classification, stable evidence serialization,
  indexed resource joins and print expansion/restoration. SDK retry defaults and
  read-only collection remain unchanged.

## Quality

- Latest final-audit source regression: **1771 passed, 6 failed** in Codex;
  all six failures are Chrome startup restrictions before page load. Separately,
  the user reported **6 passed, 1771 deselected in 2.46s** in a normal Omarchy
  terminal with Google Chrome's sandbox enabled. These are separate runs, not
  one independently executed full-suite pass.
- Ruff: zero errors. Black: 162 compliant Python files. Fixture-provider audits
  preserve the same providers/scopes; the formatting-only phase changes no AST.
- Wheel/sdist content, metadata, installation and offline CLI smoke checks are
  documented in the [final release gate](v0.5.1-final-release-gate.md). Twine and
  remote publication-availability checks remain required before publication.
- Synthetic regressions cover all Lead patterns, incomplete/conflicting evidence,
  deterministic output, HTML injection, graph limits and snapshot compatibility.
  Browser assertions cover navigation, filtering, mobile layout, print and XSS.

## Upgrade and compatibility

After publication, upgrade with `pipx upgrade awsherlock` or
`python -m pip install --upgrade awsherlock` in a virtual environment.
Python **3.11+** is required; runtime dependencies are unchanged. The 42 checks,
11 supported services, seven default services and five Lead patterns remain.
Snapshot v1/v2, existing scan JSON, Lead IDs, Lead Delta, Evidence Packs,
Coverage Diagnostics and CLI thresholds retain their existing contracts.
Contextual investigation JSON is an additive schema-v1 artifact with priority
policy v1. No snapshot v3, migration or new account permissions are required.

## Known limitations

- **Live AWS validation has not been performed.** Current evidence comes from
  synthetic fixtures and offline replay. Cross-platform CI and Trusted Publishing
  have not been executed as part of the local audit.
- Configuration indicators do not establish internet reachability, effective IAM
  permissions, credential access, exploitation or a verified attack path. Asset
  criticality remains unknown without an authoritative input. Missing evidence
  is uncertainty, not safety; provisional priority is not an impact estimate.
- Automated Chrome validation was reported by the user; manual visual review
  was not reported. Codex-local Chrome remains blocked by host IPC restrictions.
  Reports and snapshots contain sensitive identifiers and require careful handling.
