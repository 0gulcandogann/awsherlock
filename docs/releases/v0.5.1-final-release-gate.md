## Fail-closed remote preflight (normal terminal)

Run immediately before an authorized tag push. A 200 means conflict; only a
confirmed 404 for every resource permits proceeding. Network/DNS, rate limits,
authentication and other HTTP errors are blockers, not evidence of absence.

```bash
.venv/bin/python - <<'PY'
import urllib.error
import urllib.request
urls = [
    'https://pypi.org/pypi/awsherlock/0.5.1/json',
    'https://api.github.com/repos/0gulcandogann/awsherlock/git/ref/tags/v0.5.1',
    'https://api.github.com/repos/0gulcandogann/awsherlock/releases/tags/v0.5.1',
]
for url in urls:
    try:
        request = urllib.request.Request(url, headers={'User-Agent': 'AWSherlock-release-preflight'})
        with urllib.request.urlopen(request, timeout=15):
            raise SystemExit('CONFLICT: target already exists: ' + url)
    except urllib.error.HTTPError as error:
        if error.code != 404:
            raise
        print('AVAILABLE (HTTP 404):', url)
PY
```
