# Security

AWSherlock is a read-only configuration scanner. Findings are indicators for
review, not guarantees of vulnerability or security. A complete scan describes
coverage of supported checks only. Treat reports and snapshots as sensitive.

For a suspected vulnerability in AWSherlock, use the repository's private
security reporting option when available, or contact the maintainer through
their GitHub profile to arrange a private channel. Do not post credentials,
private account data or exploitable sensitive details in a public issue.
Include affected version, a synthetic reproduction and expected versus actual
behavior. No response-time or support-period guarantee is currently offered.

For a false positive or missing detection, a public issue with sanitized facts
and the check ID is appropriate. Never include secret values or live credentials.
